## 下载和使用

发布页：[v0.1.0](https://github.com/FasenChen/TV-UITree/releases/tag/v0.1.0)。

建议下载附件 `tv-uitree-v0.1.0.zip`。附件从发布提交的受跟踪文件生成，配置文件替换为以下示例；文档中与本机配置相同的设备地址和 ADB 路径也替换为占位值。运行代码保持与发布提交一致。压缩包不含 `.git`、`.venv`、`.omo`、采集产物或本地日志。

```json
{
  "TV_IP_Address": "YOUR_TV_IP",
  "port": 5555,
  "adb": "adb"
}
```

解压后，在包内修改 `config.json`：将 `YOUR_TV_IP` 改为电视 IP 或主机名；将 ADB 加入 PATH，或将 `adb` 改为本机完整路径。电视需开启 ADB 调试。在解压目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py observe --out observe.json
```

MCP 接入步骤见根目录 README。`SHA256SUMS.txt` 用于核对附件完整性：

```powershell
Get-FileHash -Algorithm SHA256 .\tv-uitree-v0.1.0.zip
```

GitHub 自动提供的 Source code ZIP/TAR.GZ 是原始 Git 快照，包含仓库原有配置；建议使用经过配置脱敏的命名附件。这是源码运行包，需要 Python 3.10+、依赖及 ADB。
