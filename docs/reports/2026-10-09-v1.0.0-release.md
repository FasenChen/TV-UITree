# v1.0.0 正式版发布记录

日期：2026-10-09。仓库：`FasenChen/TV-UITree`。前一版本：`v0.2.0`。发布页：[v1.0.0](https://github.com/FasenChen/TV-UITree/releases/tag/v1.0.0)。

## 版本范围

以本机 `main` 当前实现为基准发布正式版，包含截至 `f7b9ef3` 的代码、已完成的性能报告和本次发布文档；没有新增生产功能。

- USB ADB：CLI、MCP 读取工具和压测入口均支持精确序列号选择；与显式网络参数互斥，不回退到其他设备。
- MCP 工具名称：`observe_tv` 改为 `get_screen_summary`，`get_visible` 改为 `get_visible_controls`。
- 默认设备设置：旧 `set_default_device` 拆分为 `set_default_network_device` 与 `set_default_usb_device`；客户端升级后需刷新工具列表并修改旧调用。
- 现场采集脚本分别采集双源与仅无障碍模式，展示当前画面、焦点、返回内容及调用阶段耗时，跳过设备设置工具。
- 压测脚本自动生成图表、Markdown 和可离线打开的 HTML；默认输出到忽略目录 `report/`，支持从已有数据重新生成报告。
- 归档 USB 与网络 ADB 性能报告及六张统计图。该报告引用此前实测，本次发布没有重新进行 30 轮压测。

保留 CLI、完整树 JSON、R0–R3 证据、焦点歧义和截图坐标约定。MCP 旧工具名迁移属于有意的接口变化，不提供旧名称别名。

## 下载与配置

建议下载 `tv-uitree-v1.0.0.zip`，并用 `SHA256SUMS.txt` 核对 SHA-256。这是源码运行包，需要 Python 3.10+、ADB、项目依赖及已开启调试的电视。

源码包不包含 `docs/`、虚拟环境、Git 元数据、内部工具状态、`report/`、`_temp/` 或原始设备捕获。在线文档入口保留在根目录 README。包内配置以及本次提交的 `config.json` 使用 `YOUR_TV_IP`、端口 `5555` 和命令 `adb`；本机实际配置按原字节保留，不提交设备地址、序列号或本机 ADB 路径。既有 Git 历史未重写。

网络连接需填写电视地址；USB 连接可将配置替换为 `{"serial": "USB_SERIAL", "adb": "adb"}`，并填入实际序列号。安装和 MCP 接入步骤见根目录 README。
