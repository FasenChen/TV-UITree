# v0.2.0 发布记录

日期：2026-10-08。仓库：`FasenChen/TV-UITree`。前一版本：`v0.1.0`。发布页：[v0.2.0](https://github.com/FasenChen/TV-UITree/releases/tag/v0.2.0)。

## 版本变化

- 修复 dumpsys 消息队列等非 View 内容变化引起的层次漂移误报，复用现有 View 解析器；真实 View 变化仍可检测。
- 新增 `scripts/bench_mcp.py`，串行轮换比较 MCP 读取工具、a11y 变体和直接截图，复用 stderr 埋点记录客户端、服务端及各阶段耗时。包含预热、成功率、分位数、同轮比较和前后场景检查。
- 新增[压测使用文档](../bench-mcp.md)和[HTML 实测报告](2026-10-08-mcp-benchmark.html)，支持交互比较、阶段拆解、逐次样本、数据下载及打印。
- 归档本轮真机数据验收、漂移修复和 Channel Scan 复验报告。

生产 CLI/MCP 返回字段和计时日志契约保持不变。HTML 是本轮已生成的离线报告；压测脚本自动输出仍为 TXT、JSON 和 JSONL。

## 下载与启动

下载命名附件 `tv-uitree-v0.2.0.zip`，按根目录 README 创建虚拟环境、安装 `requirements.txt`，并填写包内 `config.json` 的 `YOUR_TV_IP`；ADB 默认使用 PATH 中的 `adb`。这是源码运行包，需要 Python 3.10+、ADB 和已开启 ADB 调试的电视。

附件从版本提交生成，配置及文档中的本机连接示例替换为占位值，不包含虚拟环境、Git 元数据、原始设备捕获或本地日志。GitHub 自动生成的 Source code 附件是原始仓库快照，建议使用命名 ZIP。`SHA256SUMS.txt` 提供命名 ZIP 的 SHA-256。
